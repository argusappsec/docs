# ADR 0001 — This repository publishes the Guide; it does not own it

**Status:** Accepted
**Date:** 2026-07-30

## Context

The Guide is authored in `argusappsec/argus`, alongside the code it documents,
so an agent changing a default can change its documentation in the same pull
request. The site that publishes it lives here. The obvious reading of that
split — "written there, official here" — gives the same sentence two homes and
no authority, which is how these arrangements rot.

## Decision

**This repository is a Publisher.** It owns the site, the Landing, navigation,
Translations, hosting and the design system. It does not own a single word of
English prose in the Guide: inside this repository the Mirror is read-only.

A second repository is justified on that basis and not on convenience: `argus`
is a Go repository whose release cadence is a binary's, while this one is a Node
toolchain whose cadence is a website's, and Translations have nothing to do with
either.

## Consequences

- **A typo spotted on the site cannot be fixed here.** It is fixed in
  `argusappsec/argus` and arrives by Sync. Accepted deliberately: the case that
  matters more is an agent updating code and documentation together, and that
  case only works if the Guide's home is the code's home.
- **Translations become tractable.** English and its Translations never share a
  file, so the Sync can overwrite English without any risk to work owned here —
  a property of the layout rather than of anyone's discipline.
- **Requirements can arrive from the other repository.** `argus` ADR 0022 places
  three on this one: mount the Mirror at `src/content/docs/guide/`, relabel the
  autogenerated sidebar groups, and serve from the domain root. They are
  received constraints, not decisions taken here.
